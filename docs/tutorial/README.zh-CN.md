# 使用文档

首次运行建议按顺序阅读：

1. [基础](00-basics.zh-CN.md)：区分目标检测、语义分割和实例分割。
2. [环境](01-environment.zh-CN.md)：安装锁定环境并检查设备。
3. [数据与实例](02-data-and-instances.zh-CN.md)：下载 Penn-Fudan、校验 manifest、预览实例，或准备 COCO JSON。
4. [Mask R-CNN](03-maskrcnn.zh-CN.md)：理解训练/评估 forward 契约和模型 head。
5. [训练](04-training.zh-CN.md)：dry-run、训练、选择 `best.pt` 和从 `last.pt` 恢复。
6. [评估与推理](05-evaluation-and-inference.zh-CN.md)：生成指标、错误报告、overlay 和单图产物。

需要快速查询命令与输出时，阅读 [CLI 与输出参考](../reference/cli-and-outputs.zh-CN.md)。每章旁边的同名 `.md` 文件是英文版本。
