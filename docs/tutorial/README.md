# Usage Documentation

Follow the pages in order for a first run:

1. [Basics](00-basics.md): distinguish detection, semantic segmentation, and instance segmentation.
2. [Environment](01-environment.md): install the locked environment and check the device.
3. [Data and instances](02-data-and-instances.md): download Penn-Fudan, verify manifests, preview instances, or prepare COCO JSON.
4. [Mask R-CNN](03-maskrcnn.md): understand training/evaluation forward contracts and model heads.
5. [Training](04-training.md): dry-run, train, select `best.pt`, and resume from `last.pt`.
6. [Evaluation and inference](05-evaluation-and-inference.md): generate metrics, error reports, overlays, and single-image artifacts.

For a compact command/output lookup, use the [CLI and outputs reference](../reference/cli-and-outputs.md). For Chinese, use the matching `.zh-CN.md` page beside each chapter.
